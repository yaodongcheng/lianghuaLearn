# 技术指标标准公式

> 用途：实现任何指标前对照这里的标准定义；写完后检查代码与公式是否一致。
> 口径说明：以下采用**国内行情软件（同花顺/通达信）**的通用口径。

---

## MACD（指数平滑异同移动平均线）

**公式**：
```
EMA12 = 收盘价的 12 日指数移动平均
EMA26 = 收盘价的 26 日指数移动平均
DIF   = EMA12 − EMA26
DEA   = DIF 的 9 日指数移动平均
BAR（红柱/绿柱）= 2 × (DIF − DEA)     ← ×2 是国内软件口径，国外为 1×
```

**pandas 实现要点**：`series.ewm(span=N, adjust=False).mean()` 即 N 日 EMA。

**常见信号**：
- 金叉：DIF 上穿 DEA → 看多
- 死叉：DIF 下穿 DEA → 看空
- 底背离/顶背离：价格创新低/新高但 DIF 没有 → 可能反转（进阶用法）

**易错点**：
- EMA 初始值取法不同，前 30 根左右数值与行情软件略有差异，**正常**，不影响交叉信号
- 判断"上穿"要用前后两天比较：`今天 DIF>DEA 且 昨天 DIF≤DEA`

## KDJ（随机指标）

**公式**（默认参数 9, 3, 3）：
```
RSV = (当日收盘 − 9日最低价) / (9日最高价 − 9日最低价) × 100
K = SMA(RSV, 3, 1)   → 即 K = (2/3)×昨日K + (1/3)×今日RSV
D = SMA(K, 3, 1)     → 即 D = (2/3)×昨日D + (1/3)×今日K
J = 3K − 2D
```

**pandas 实现要点**：国内的 `SMA(X, 3, 1)` 等价于 α=1/3 的指数平滑，即 `X.ewm(com=2).mean()`（因为 α = 1/(1+com)，com=2 → α=1/3）。

**常见信号**：
- K、D < 20：超卖区，可能反弹；> 80：超买区，可能回落
- J < 0 或 J > 100：极端超卖/超买
- K 上穿 D（金叉）看多，下穿（死叉）看空

**易错点**：行情软件里 K、D 初始值通常取 50，且从第 9 天才开始显示；自己实现时早期数值不同属正常。

## MA（移动平均线）

```
SMA（简单均线）= 最近 N 日收盘价的算术平均
EMA（指数均线）= 越近的价格权重越大，pandas: close.ewm(span=N, adjust=False).mean()
```

**常见信号**：
- 金叉死叉：短均线（如 MA5）上穿/下穿长均线（如 MA20）
- 价格站上/跌破均线：MA20 常被视为"生命线"，MA60 为中期趋势线
- 多头排列：MA5 > MA10 > MA20 > MA60，强趋势特征

**常用参数**：5、10、20、60、120、250（年线，约 250 个交易日）。

---

## RSI（相对强弱指标）

**公式**（Wilder 威尔德平滑法，常用 N=6, 12, 24）：
```
涨跌 Δ = 今日收盘 − 昨日收盘
UP   = max(Δ, 0)，DOWN = max(−Δ, 0)
平均涨幅 = UP 的 Wilder 平滑   →  pandas: UP.ewm(alpha=1/N, adjust=False).mean()
平均跌幅 = DOWN 的 Wilder 平滑
RS  = 平均涨幅 / 平均跌幅
RSI = 100 − 100 / (1 + RS)
```

**常见信号**：RSI > 80 超买、< 20 超卖（也有用 70/30 的）；50 是多空分界线。

**易错点**：RSI 有两种平滑口径（Wilder 平滑 vs 简单平均），国内软件用 Wilder 平滑。用 `rolling(N).mean()` 简单平均算出来的值会不同，不算错，但和行情软件对不上。

## BOLL（布林带）

**公式**（默认 N=20, 倍数 K=2）：
```
中轨 = 20 日 MA
标准差 σ = 最近 20 日收盘价的标准差
上轨 = 中轨 + 2σ
下轨 = 中轨 − 2σ
```

**常见信号**：
- 价格触及上轨：偏强但也可能超买；触及下轨：偏弱但也可能超卖
- 带宽收窄（上下轨靠拢）后突然张口：往往预示大行情启动

**易错点**：标准差有"样本标准差"（pandas 默认 `ddof=1`）和"总体标准差"（`ddof=0`）之分，不同软件口径不同，数值差一点属正常。

## BIAS（乖离率）

**公式**（常用 N=6, 12, 20）：
```
BIAS(N) = (当日收盘 − N日移动平均价) / N日移动平均价 × 100%
```

**含义**：价格偏离均线的百分比。MA(N) 可理解为"最近 N 天买入者的平均成本"，
BIAS 为负且绝对值大 = 现价明显低于近期平均成本 = 短期超跌（恐慌）。
对"跌得快"敏感（均线是平均值，价格急杀会瞬间偏离它），天然捕捉短期超跌；
与"距前高回撤"不同——后者对"跌得久"也敏感，容易在阴跌途中反复触发。

**常见信号**（指数口径，个股波动大阈值需放宽）：BIAS20 ≤ -6% 超卖；BIAS20 ≥ +6% 超买。

**实测参考**（2026-07-25，上证/沪深300 抄底回测）：BIAS20≤-6% 是六种超跌定义中
综合最佳（详见 [zhihu/吃超跌恐慌修复策略.md](zhihu/吃超跌恐慌修复策略.md)）。

## 指标家族的直觉理解：位移、速度、加速度（2026-07-28 问答沉淀）

> 用途：公式告诉你"怎么算"，这一节告诉你"算出来的东西像什么"——
> 实现指标时如果连直觉都对不上（比如把 DIF 当成加速度理解），多半会写出似是而非的代码。

### 求导族：价格 → 速度 → 加速度

把收盘价当成车的**里程表**（位移），那么：

| 物理量 | 指标对应 | 说明 |
|---|---|---|
| 位移 | 收盘价；均线 = 平滑后的位移 | |
| 速度（位移的变化） | 日涨跌幅；动量 MTM = 今收 − N日前收 | N 日动量 ÷ N = 平均速度 |
| 加速度（速度的变化） | 今日涨幅 − 昨日涨幅 | 原始加速度，噪声巨大，没人直接用 |

**DIF 是速度，不是加速度。** 直觉推导：稳定上涨时，N 日均线总是"拖后"约半条窗口
——12 日线 ≈ 5.5 天前的价格，26 日线 ≈ 12.5 天前的价格。所以
DIF = EMA12 − EMA26 ≈ **最近 7 天的涨幅 ≈ 速度 × 7**（7 是刻度，不是误差）。
关键洞察：不是"做一次减法就升一阶导数"，要看**减的两个量各是什么**——
DIF 是"同一时刻、两条平滑位移之差"，仍是一阶量；加速度需要"速度在两个时刻之差"。

**MACD 柱才是加速度计。** DEA 是 DIF 的 9 日平滑（≈ 拖后 4 天的速度），
柱 = 2×(DIF − DEA) ≈ 速度在这几天里的变化 × 常数 = **平滑版加速度**。

开车翻译：
- 金叉（DIF 上穿 DEA）≈ 确认"开始踩油门"——车（价格）可能早就在滑行前进，所以金叉天然滞后
- 死叉 ≈ 开始踩刹车——车还在往前冲，所以死叉总是卖得"太晚"
- 红柱缩头 = 加速度减小：还在涨但油门松了 → 比死叉更早的预警（加速度领先速度，速度领先位移）
- 顶背离 = 里程表新高但车速表一波比一波低 = 上坡减速，快到坡顶

**"几种加速度"的区别**：原始加速度（今日涨幅 − 昨日涨幅）最灵敏但噪声爆炸；
MACD 柱用 EMA 滤波降噪，代价是滞后。**阶数越高越先行、噪声越大；滤波越重越平滑、越滞后**
——所有指标都是在这对矛盾里选位置，参数就是旋钮。

### KDJ 不在求导族：它是"车在赛道里的位置"

RSV = (今收 − 9日最低) / (9日最高 − 9日最低) × 100 = **当前价格在最近 9 天区间里的
相对位置**（0 = 贴地，100 = 顶天），与"速度/加速度"无关。
赛车类比：最近 9 天的最高/最低价是赛道的上下两面墙，RSV 报告车贴着哪面墙跑——
强势市场的特征是收盘总贴上墙；开始贴下墙 = 司机没劲了。
K、D 是 RSV 的两级平滑（悬挂减震）；J = K + 2×(K − D) 把 K 偏离 D 的部分放大外推
= 拆掉减震器换灵敏度，所以 J 能冲出 0~100（撞出赛道 = 极端读数）。

⚠ 类比边界：位移/速度/加速度只覆盖"价格求导族"（动量/均线/MACD）；
KDJ/RSI 是"归一化震荡族"——把价格压缩进 0~100 回答"极端不极端"，不问"跑多快"。

### RSI = 速度的"单边程度"

RSI = 100 × 平均涨幅 ÷（平均涨幅 + 平均跌幅），读作"最近 N 天的速度里，向上的占几成"。
⚠ 新手最常见的误读：**RSI 高 ≠ 涨得多，= 涨得"顺"**——每天涨 0.3%、从不回调，
RSI 也能到 90+；一天暴涨 10% 然后横盘，RSI 反而只有中等。

### 超买超卖：橡皮筋读数

**超买/超卖 = 价格相对近期常态"涨过头/跌过头"的状态**（是状态，不是事件）：
RSI 或 KDJ 的 D > 80 / < 20，BIAS20 超 ±6%，BOLL 出轨。
背后的多空逻辑：涨过头 → 短线获利盘丰厚、回吐压力积聚；跌过头 → 恐慌盘出清、卖压枯竭。
所以它是**均值回复派**的参考（门派划分见 [timing_signals.md](timing_signals.md)）。

三条纪律：
1. **超买之后还能超买**：强趋势里 RSI 可以贴着 80 走几周（这叫"钝化"），
   超买在震荡市好用、在单边市会被碾过去（[strategy_fit.md](strategy_fit.md)）
2. 超买超卖是"橡皮筋拉长了"，不是"必须马上弹回"——它可以继续拉
3. A股只能做多：超买的真实用途 = 减仓/离场参考（[exit_rules.md](exit_rules.md)），
   超卖 = 抄底参考（本项目六种超卖定义实测见 [zhihu/吃超跌恐慌修复策略.md](zhihu/吃超跌恐慌修复策略.md)）
