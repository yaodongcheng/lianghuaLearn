# 技术指标标准公式

> 用途：实现任何指标前对照这里的标准定义；写完后检查代码与公式是否一致。
> 口径说明：以下采用**国内行情软件（同花顺/通达信）**的通用口径。

---

## MACD（指数平滑异同移动平均线）

**公式**：
```
EMA12 = 收盘价的 12 日指数移动平均
EMA26 = 收盘价的 26 日指数移动平均
DIF   = EMA12 − EMA26
DEA   = DIF 的 9 日指数移动平均
BAR（红柱/绿柱）= 2 × (DIF − DEA)     ← ×2 是国内软件口径，国外为 1×
```

**pandas 实现要点**：`series.ewm(span=N, adjust=False).mean()` 即 N 日 EMA。

**常见信号**：
- 金叉：DIF 上穿 DEA → 看多
- 死叉：DIF 下穿 DEA → 看空
- 底背离/顶背离：价格创新低/新高但 DIF 没有 → 可能反转（进阶用法）

**易错点**：
- EMA 初始值取法不同，前 30 根左右数值与行情软件略有差异，**正常**，不影响交叉信号
- 判断"上穿"要用前后两天比较：`今天 DIF>DEA 且 昨天 DIF≤DEA`

## KDJ（随机指标）

**公式**（默认参数 9, 3, 3）：
```
RSV = (当日收盘 − 9日最低价) / (9日最高价 − 9日最低价) × 100
K = SMA(RSV, 3, 1)   → 即 K = (2/3)×昨日K + (1/3)×今日RSV
D = SMA(K, 3, 1)     → 即 D = (2/3)×昨日D + (1/3)×今日K
J = 3K − 2D
```

**pandas 实现要点**：国内的 `SMA(X, 3, 1)` 等价于 α=1/3 的指数平滑，即 `X.ewm(com=2).mean()`（因为 α = 1/(1+com)，com=2 → α=1/3）。

**常见信号**：
- K、D < 20：超卖区，可能反弹；> 80：超买区，可能回落
- J < 0 或 J > 100：极端超卖/超买
- K 上穿 D（金叉）看多，下穿（死叉）看空

**易错点**：行情软件里 K、D 初始值通常取 50，且从第 9 天才开始显示；自己实现时早期数值不同属正常。

## MA（移动平均线）

```
SMA（简单均线）= 最近 N 日收盘价的算术平均
EMA（指数均线）= 越近的价格权重越大，pandas: close.ewm(span=N, adjust=False).mean()
```

**常见信号**：
- 金叉死叉：短均线（如 MA5）上穿/下穿长均线（如 MA20）
- 价格站上/跌破均线：MA20 常被视为"生命线"，MA60 为中期趋势线
- 多头排列：MA5 > MA10 > MA20 > MA60，强趋势特征

**常用参数**：5、10、20、60、120、250（年线，约 250 个交易日）。

## RSI（相对强弱指标）

**公式**（Wilder 威尔德平滑法，常用 N=6, 12, 24）：
```
涨跌 Δ = 今日收盘 − 昨日收盘
UP   = max(Δ, 0)，DOWN = max(−Δ, 0)
平均涨幅 = UP 的 Wilder 平滑   →  pandas: UP.ewm(alpha=1/N, adjust=False).mean()
平均跌幅 = DOWN 的 Wilder 平滑
RS  = 平均涨幅 / 平均跌幅
RSI = 100 − 100 / (1 + RS)
```

**常见信号**：RSI > 80 超买、< 20 超卖（也有用 70/30 的）；50 是多空分界线。

**易错点**：RSI 有两种平滑口径（Wilder 平滑 vs 简单平均），国内软件用 Wilder 平滑。用 `rolling(N).mean()` 简单平均算出来的值会不同，不算错，但和行情软件对不上。

## BOLL（布林带）

**公式**（默认 N=20, 倍数 K=2）：
```
中轨 = 20 日 MA
标准差 σ = 最近 20 日收盘价的标准差
上轨 = 中轨 + 2σ
下轨 = 中轨 − 2σ
```

**常见信号**：
- 价格触及上轨：偏强但也可能超买；触及下轨：偏弱但也可能超卖
- 带宽收窄（上下轨靠拢）后突然张口：往往预示大行情启动

**易错点**：标准差有"样本标准差"（pandas 默认 `ddof=1`）和"总体标准差"（`ddof=0`）之分，不同软件口径不同，数值差一点属正常。
