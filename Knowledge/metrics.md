# 绩效指标标准算法

> 用途：回测结束后评估策略好坏，并与大盘基准对比。这里的公式是统一口径，写代码时照此实现。

**前置概念——净值曲线**：把账户总资产（现金+持仓市值）按时间连成线，初始值归一化为 1。净值从 1 涨到 1.5 = 赚了 50%。几乎所有指标都从净值曲线（或日收益率序列）推导。

---

## 1. 收益类

**累计收益率**
```
累计收益 = 期末净值 / 期初净值 − 1
```

**年化收益率（CAGR）**——不同时间长度的策略才能公平比较
```
年化收益 = (期末净值 / 期初净值) ^ (1 / 年数) − 1
```
年数的两种口径（结果接近，选定一个保持统一即可）：
- **日历年化**：年数 = 自然天数 / 365.25 ⭐ 本项目统一口径（quant/metrics.py），
  与 v1~v4 全部历史报告可比，且不依赖"一年几个交易日"的假设
- 交易日年化：年数 = 交易天数 / 252（A股一年约 250 个交易日，252 或 250 皆可）
  ——8 年区间两者差约 0.2 个百分点，属噪声级差异，但跨报告对比时必须同口径

---

## 2. 风险类

**最大回撤（Max Drawdown）**⭐ 最重要的风险指标
```
回撤 = 净值 / 历史最高净值 − 1      （每天算一个，≤0）
最大回撤 = 回撤序列的最小值
```
含义：从最高点最多亏过多少。比如 −30% 表示曾经从 100 万亏到 70 万。
```python
drawdown = nav / nav.cummax() - 1
max_drawdown = drawdown.min()
```

**年化波动率**
```
日收益率 std × √252
```

---

## 3. 风险调整后收益

**夏普比率（Sharpe Ratio）**——每承受一份波动，换来多少超额收益
```
夏普 = (年化收益 − 无风险利率) / 年化波动率
```
无风险利率常取 3%（约等于国债/货基收益），懒人算法也可取 0，但要在报告里注明。

**卡玛比率（Calmar Ratio）**——每承受一份最大回撤，换来多少收益
```
卡玛 = 年化收益 / |最大回撤|
```

---

## 4. 交易统计类

```
胜率   = 盈利交易次数 / 总交易次数
盈亏比 = 平均每笔盈利 / 平均每笔亏损
```
注意：**胜率高 ≠ 赚钱**。胜率 40% 但盈亏比 3:1（亏小赚大）的策略，比胜率 70% 但盈亏比 0.5:1（赚小亏大）的好得多。

---

## 5. 与基准对比

```
超额收益（年化）= 策略年化收益 − 基准年化收益
```
- 基准选择见 [data_sources.md](data_sources.md)：A股用沪深300，港股用恒生指数
- 画图：策略净值与基准净值**归一化到同一起点 1**，画在同一张图上
- 进阶（后续再学）：Alpha / Beta / 信息比率

## "什么算好"——直觉参考表

| 指标 | 及格 | 不错 | 很好 | 先怀疑有 bug |
|---|---|---|---|---|
| 年化收益 | > 8% | > 15% | > 25% | > 50%（查未来函数！） |
| 最大回撤 | < 30% | < 20% | < 10% | 接近 0 且收益高（不真实） |
| 夏普比率 | > 0.5 | > 1 | > 2 | > 3 |
| 卡玛比率 | > 0.5 | > 1 | > 2 | — |

**常识锚点**：巴菲特长期年化约 20%，西蒙斯的大奖章基金（扣除费用后）年化约 39%，已是人类历史顶级水平。你的策略如果轻松超过他们，先回头查 [backtest_checklist.md](backtest_checklist.md)。
