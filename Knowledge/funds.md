# 场外基金知识（支付宝渠道必读）

> 用户没有股票账户，实际交易工具是支付宝上的**场外基金**。基金的成交规则、费用、数据形态都和股票不同——回测必须按基金的规则来，否则结论没有实操意义。

---

## 一、场外 vs 场内（先分清）

| | 场内基金（ETF） | 场外基金 |
|---|---|---|
| 交易方式 | 像股票一样盘中实时撮合 | 向基金公司申购/赎回 |
| 成交价 | 盘中实时价格 | **一天只有一个价：当晚公布的净值** |
| 账户要求 | 需要股票账户 ❌ | 支付宝/天天基金等即可 ✅ |
| 用户的战场 | 买不了 | **这里就是主战场** |

补充：**ETF联接基金**是场外基金，专门跟踪某只 ETF（如"沪深300ETF联接"），是没有股票账户时买指数的主要方式。

**联接C vs 场内ETF 收益并不一样**（2026-07-25 用 富国上证指数ETF联接C 013286 vs 上证综指ETF 510210 实测，近一年）：
- 联接C 净值 +5.76% / 场内ETF 价格 +6.73% / 上证指数 +5.78% → **一年差约 1%**
- 归因：联接基金跟踪的是"ETF 的净值"≈指数（实测与指数误差仅 -0.02%，C 类服务费拖累被基金打新/借券等增强收益抵消）；而那 1% 差距主要来自**场内 ETF 价格跑赢指数**（ETF 自身增强 + 溢价扩张）
- 其他差异：场内盘中实时成交有折溢价、佣金万几（无印花税）；场外按当晚净值成交无折溢价，但 C 类按日计提销售服务费
- 结论：没有股票账户时联接基金就是 ETF 平替，~1%/年的差距可视为"门票钱"；长持比较 A/C 类费用更重要
- 数据注意：新浪 ETF 接口（`fund_etf_hist_sina`）**只有不复权价格**，ETF 若分红会低估真实收益（分红除息日价格会跳水）

## 二、场外基金交易规则（回测必读）

1. **一天一个价**：净值（NAV）每晚公布，盘中下单时并不知道成交价
2. **15:00 cutoff**：交易日 15:00 前提交 → 按**当晚净值**成交；15:00 后提交 → 顺延到下一交易日净值
3. **确认与到账**：申购 T+1 确认份额（QDII 基金 T+2）；赎回到账 T+1 ~ T+7
4. **费用**：
   | 费用 | 水平 | 说明 |
   |---|---|---|
   | 申购费 | 原 1.5%，支付宝通常 1 折 ≈ **0.15%** | C 类份额免申购费 |
   | 赎回费 | **持有 <7 天：1.5%（惩罚性！）**；7 天~1 年：0.5%→0.05% 递减；>2 年多为 0 | 规则里最要命的一条 |
   | 销售服务费 | C 类按日计提（约 0.2%~0.8%/年） | A 类不收 |
   | 管理/托管费 | 每年 0.5%~1.5%，**已从净值中扣除** | 回测不用重复计算 |
5. **A 类 vs C 类**：A 类收申购费、无日计提；C 类免申购费、按日收销售服务费 → **短持选 C，长持选 A**（临界点通常在半年~一年）

## 三、对策略设计的影响 ⭐

1. **短线交易死刑**：<7 天赎回费 1.5%，一进一出至少亏 1.65% → **调仓周期 ≥ 2 周，月级更佳**。适合基金的策略：指数动量轮动、股债再平衡、定投+估值止盈
2. **"信号日 = 成交日"可以成立**（和股票不同！）：只要信号能在 15:00 前算出（即用**昨日及之前**的数据），当天 15:00 前下单就按当晚净值成交
   - 反过来：如果信号要用**今日收盘**数据才能算出 → 只能按**下一交易日**净值成交
   - 写回测时必须想清楚自己的信号属于哪种，这决定了"未来函数"的判定方式
3. **无涨跌停、无 T+1**：基金没有这些限制（QDII 有溢价/限购问题，初期避开）
4. **数据形态简单**：一天一个净值，没有开高低收，回测粒度天然是"日"

## 四、akshare 基金数据接口

```python
import akshare as ak

# 场外基金历史净值（symbol 是基金代码，如 110011 易方达中小盘）
df = ak.fund_open_fund_info_em(symbol="110011", indicator="单位净值走势")

# ETF 行情（用于对照，或作为联接基金的锚）
df_etf = ak.fund_etf_hist_em(symbol="510300", period="daily", adjust="qfq")

# 基金列表（查代码用）
fund_list = ak.fund_name_em()
```

**常见可投标的举例**（支付宝可购）：
- 沪深300 / 中证500 的指数基金或 ETF 联接
- 恒生科技 ETF 联接（QDII，投港股，受外汇额度影响可能限购）
- 纳指 / 标普 QDII 基金

注意：基金净值数据**天然是复权的**（分红再投资体现在"累计净值"里），回测优先用**累计净值**，别用单位净值。
更精确的说法（2026-07-24 补充）：累计净值 = 单位净值 + 历史分红**简单相加**，不含分红再投资的复利。
~~要算精确总回报，用"日增长率"连乘最稳妥~~ **2026-07-27 更正**：东财接口的日增长率（daily_ret）
**在除息日把分红当亏损**（实测 160119 于 2026-07-24 除息：daily_ret -2.47% vs 累计净值涨幅 -2.36%），
连乘会**低估**总回报 → 实操用 `acc_nav.pct_change()` 最稳（口径=分红简单相加不再投资，与精确值差异很小）。
没分过红的基金（年轻人基金居多）单位净值=累计净值，不纠结。

**本项目实测（2026-07-24）**：
- 东财基金 F10 接口（`fund_open_fund_info_em`，主机 fundf10.eastmoney.com）在本网络**可用**——被防火墙拦的只是行情 push2 系主机，基金接口不受影响
- 查基金代码用 `ak.fund_name_em()` 按名称过滤（示例：永赢先锋半导体智选混合发起C = `025209`，A 类 = `025208`）
- **当日净值晚上才公布**：白天支付宝里的"估值"是第三方按上季重仓股估算的，不是成交价，也不是真实净值——基金没有"盘中实时数据"可拉，这点和股票 `fetch_spot_bar` 不同

**本项目实测（2026-07-25）**：
- **"同类平均涨幅"免费接口拿不到**：支付宝/天天基金展示的"同类平均"曲线是平台按基金分类算的均值，`fund_open_fund_info_em(indicator="同类排名走势")` 只返回**排名**（同类排名 + 全市场排名，近三月口径），不含平均涨幅序列 → 同类定位只能用排名替代（已封装 `fetch_fund_rank`，quote.py 基金查询默认展示）
- **主动基金没有官方"所属行业指数"**：持仓一季度才披露且会变，想对比行业只能手动选相关行业指数（quote.py 用 `--bench 指数别名/代码`）

## 五、适合场外基金的策略类型（新手友好度排序）

1. **股债再平衡**（如 60% 股票指数 + 40% 债券，每季度/半年再平衡一次）——最经典，调仓极少，费用几乎为零
2. **指数动量轮动**（沪深300 / 中证500 / 创业板指，谁的近 20~25 日涨幅高就持有谁，月度调仓）——有明确学术依据（动量效应）
   - **2026-07-27 实测（[plans/04](../plans/04-fund-strategy.md)，16.7 年联接基金数据）：理想化有效、实盘摩擦后失效**。信号层面（零费+每日检查）+342%，但：
     ① 月度调仓在信号层面就失效（零费也 -34%）——轮动的精髓是每日响应，月度=自废武功
     ② A 类费率做轮动=自杀（17 年费用合计 404%，189 条 <7 天惩罚腿），**C 类是前提**
     ③ C 类+到账空窗 3 天后年化 +3.6%，**与一直持有 300 持平**，只赚回撤打 7 折；2017 年后跑输持有
     ④ 空窗成本有方向性：动量买点必然在涨途中，"晚买 3 天"错过的是最强的日子
     ⑤ 补救：同一家基金公司的 C 类对可用『基金转换』（T+1 确认、无在途空窗），但 C 类 2018 年后才普及，长样本验证不了
   - 方法论沉淀：**策略不行先跑零费版**，分清"信号烂"还是"执行摩擦烂"再决定扔不扔
3. **定投 + 估值止盈**（低估区加倍定投，高估区分批止盈）——适合长期工资理财
4. 网格交易 ❌ 不适合场外：调仓太频繁，费用会吃掉全部利润（网格是场内玩法）
