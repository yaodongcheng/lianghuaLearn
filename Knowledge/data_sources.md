## 一、数据获取：akshare

**安装**：`pip install akshare`（免费、免注册，数据来自公开网页接口）

**本项目最常用的接口**：

```python
import akshare as ak

# A股个股日线（前复权）—— symbol 不带交易所前缀
df = ak.stock_zh_a_hist(symbol="600519", period="daily",
                        start_date="20200101", end_date="20260724", adjust="qfq")

# 港股个股日线（前复权）—— 5 位代码
df_hk = ak.stock_hk_hist(symbol="00700", period="daily",
                         start_date="20200101", end_date="20260724", adjust="qfq")

# 指数（沪深300 等基准）—— 注意 adjust 传空字符串
df_idx = ak.index_zh_a_hist(symbol="000300", period="daily",
                            start_date="20200101", end_date="20260724")

# 场外基金历史净值（支付宝渠道买的就是这类，交易规则差异大，见 funds.md）
df_fund = ak.fund_open_fund_info_em(symbol="110011", indicator="单位净值走势")
```

**使用注意**：
- 返回的是中文列名（日期/开盘/收盘/最高/最低/成交量…），入库前统一重命名为 `date, open, high, low, close, volume`
- 接口本质是爬网页，**拉下来后存本地 CSV 缓存**（放 `data/` 目录），别每次回测都重新下载
- 网络波动可能导致偶发失败，重试即可

**数据源容灾（2026-07-24 实测踩坑，重要）**：
- 东财 kline 接口使用**带编号的子域名**（`33.push2his.eastmoney.com` 等），部分企业网络/防火墙会间歇性断开这类连接（报 `RemoteDisconnected`）。本项目已按"东财优先、新浪兜底"封装好双源获取，见 [wheels.md 的 fetch_daily](../wheels.md)。
- 兜底用的新浪接口：`ak.stock_zh_a_daily`（A股个股）/ `ak.stock_hk_daily`（港股）/ `ak.stock_zh_index_daily`（指数）。
- 新浪代码规则：A股个股 `sh600519`/`sz000xxx`，港股 `00700`；**A 股指数统一 `sh` 前缀**（`sh000300`），写成 `sz` 会返回畸形数据。
- 东财与新浪的前复权因子算法略有差异：**同一只票的回测始终用同一来源的缓存，不要混用**。
- 验证前复权是否生效的自洽方法（不依赖外部数据）：qfq 最新收盘价 = 当前市价；历史价格 ≤ 不复权价格。

## 二、复权（重要概念）

股票分红、送股后，股价会按比例"跳水"（除权除息）。比如 10 送 10，股价直接减半——这不是跌了 50%，是你的股数翻倍了。

| 类型 | 含义 | 适用 |
|---|---|---|
| 不复权 | 真实历史成交价，除权日有跳空缺口 | 看历史真实价格 |
| **前复权 qfq** | 以最新价为基准，把历史价格往下调 | 日常分析、回测常用 ✅ |
| 后复权 hfq | 以上市价为基准，把后来价格往上调 | 精确计算长期累计收益 |

**本项目约定：回测统一用前复权（`adjust="qfq"`）**。
注意：指数不存在分红除权，拉指数时 `adjust=""`。

### ETF 的份额拆分陷阱（2026-07-27 实测抓出）⭐

ETF 除了分红，还有**份额拆分**（1 拆 2：净值减半、份额翻倍，常见于一元面值营销）。
不复权价在拆分日会出现**假暴跌**——512480（半导体ETF）历史上两次 1 拆 2，
raw 价单日显示 **-48.9% / -50.7%**（真实当日波动只有 ±2% 左右）：

- 危害不只是收益算错：假暴跌会把 RSI 打到 0 → 触发假抄底信号；回撤统计直接爆表
- 识别方法：`check_daily()` 的"单日波动 Top5"——ETF 真实波动有 ±10% 涨跌停顶着，
  出现 -40% 以上的"单日暴跌"基本就是拆分或复权缺口
- 修复：`fetch_daily("etf", code, adjust="qfq")`（东财接口支持）。
  **注意新浪 ETF 接口没有复权参数**，所以显式请求 qfq 时轮子只走东财，
  宁可报错也不让 raw 冒充 qfq（2026-07-27 起 fetch_data.py 已内置此约束）
- 场外基金不受影响：净值序列本身就是连续的，拆分会直接调整份额和净值

## 三、A股交易规则（回测必须遵守）

| 规则 | 内容 | 对回测的影响 |
|---|---|---|
| **T+1** | 今天买入，明天才能卖出 | 买入当日触发卖出信号不能成交 |
| 涨跌停 | 主板 ±10%，ST ±5%，创业板(30xxxx)/科创板(688) ±20% | 涨停买不进、跌停卖不出 |
| 最小单位 | 买入 100 股（一手）的整数倍；卖出可零股 | 买入股数要向下取整到 100 |
| 交易时间 | 9:30–11:30, 13:00–15:00（9:15–9:25 集合竞价） | 日线回测无需关心 |
| 交易成本 | 佣金约万2.5（最低5元，双向）+ 印花税0.05%（卖出）+ 过户费约万0.1 | 来回按 0.2%~0.3% 估 |

**股票代码速查**：
- `60xxxx` 上海主板、`000xxx/001xxx` 深圳主板、`002/003` 深市
- `300xxx` 创业板（±20%）、`688xxx` 科创板（±20%）、`8xxxxx/4xxxxx` 北交所（±30%）
- 指数：`000300` 沪深300、`000001` 上证指数、`000905` 中证500

## 四、港股交易规则（后续阶段用）

| 规则 | 与 A 股的差异 |
|---|---|
| 交易制度 | **T+0**，当天可买卖（资金交收 T+2） |
| 涨跌停 | **没有**涨跌停限制 |
| 最小单位 | 每手股数因股票而异（腾讯一手 100 股，有的一手 1000 股） |
| 代码 | 5 位数字，如腾讯 `00700` |
| 成本 | 印花税 0.1%（双向）+ 佣金，比 A 股贵 |
| 港股通 | 内地账户买港股有汇率换算、额度等问题，策略验证阶段先不考虑 |
