# 波浪理论与江恩理论：内容速览与"为什么回测不了"（2026-07-28）

> 来源：用户课程知识沉淀（plans/25）。
> 定位：这两套是课程里听起来最"高深"的理论，也是**离量化最远的**。
> 本文件做三件事：内容值得知道（速览）→ 为什么无法机械回测（更重要）→
> 能提炼出什么可检验的成分（如果想较真）。

## 一句话核心

波浪理论说"市场按 5 浪推进、3 浪调整的节奏走"；江恩理论说"时间和价格可以换算，
到点必转折"。**两套都在回答同一个问题——现在走到哪了、还能走多远——
但答案依赖主观解读，写不成"如果…就…"的机械规则，因此从未通过严格统计检验。**
对量化的意义：不是操作工具，是理解"市场有节奏感"的直觉 + 一面照妖镜
（凡是不能写成机械规则的'规律'，都该先打问号）。

## 波浪理论（艾略特）速览

### 基本结构：8 浪循环

```
        5
       / \
      /   \        B
  3  /     \      / \
 /  \       \    /   \
/    2       A--     C      ← 上升趋势：1/3/5 推动浪（向上），2/4 调整浪（向下）；
1                                随后 A/B/C 三浪大调整
```

- **推动浪（1/3/5）**：顺大势的浪；**调整浪（2/4）**：逆大势的休整
- **三条铁律**（违反就不是这个数法）：
  ① 浪 2 不跌破浪 1 的起点；② 浪 3 不能是最短的一浪；③ 浪 4 低点不进入浪 1 的价格区间
- **浪中有浪（分形）**：任意一浪可细分成更小级别的 5-3 结构，级别从分钟到数十年
- **斐波那契比率**：调整浪常回撤前一浪的 0.382 / 0.5 / 0.618；浪 5 长度常 ≈ 浪 1 × 1.618
  （斐波那契数列 1,1,2,3,5,8,13…，相邻两项之比趋近 0.618，号称"自然界的比例"）

## 江恩理论速览

- **时间价格等价**："时间与价格平衡时，市场发生转折"——把时间和价格当成可互换的两个维度
- **江恩角度线**：从重要低点出发画扇形射线，1×1 线 = 每天上涨固定点数（所谓 45°），
  号称支撑/压力线；配合 1×2、2×1 等更陡/更平的线
- **回调带**：把一段涨跌幅按 1/8 分位切开（12.5%、25%、37.5%、**50%**、62.5%…），
  50% 最重要——"涨多了回一半"是常态
- **时间窗口**：重要顶底的周年日、固定天数周期（30/90/144/360…）、节气，号称易转折

## 为什么无法机械回测（本项目立场，重要）

1. **数浪是主观的**：同一段 K 线，十个分析师数出十种浪；浪中有浪意味着永远可以说
   "你看的是小级别"。规则里隐含"数错了就重新数" = **不可证伪**（任何走势都能事后解释，
   没有任何走势能证明它错）——不可证伪的理论没法回测，因为连"信号触发"都定义不出来。
2. **江恩角度线依赖图表刻度**：同一只股票，窗口放大缩小，"45° 线"的角度就变。
   数学上它没有确定定义，不同软件画出不同的线 → 连输入都不确定，谈何验证。
3. **时间窗口是幸存者偏差**：给出的"易转折日"太多，事后只记住蒙中的。
   （幸存者偏差 = 只看活下来/猜中的样本，见 [backtest_checklist.md](backtest_checklist.md)）
4. **结论**：无法机械化 = 无法回测 = 对实盘没有操作意义。留存价值是两层：
   "市场有节奏/对称感"的直觉；以及风控意识（"涨多了会回调"这件事本身是真的）。

## 可提炼的可检验成分（如果想较真）

| 理论成分 | 可检验的机械化版本 | 本项目现状 |
|---|---|---|
| 斐波那契回撤位 0.618 | 定义前高前低 → 统计"跌到 0.618 处是否更容易反弹" | 可做 analysis 统计脚本（落不进日频策略框架），**未做，另立计划再说** |
| 江恩"回一半"（50%） | 同上，本质是支撑/压力位的一种定义 | 同上 |
| "涨多了会回调" | 均值回复信号：BIAS 超跌、距前高回撤 | **已覆盖且更干净**（见 [timing_signals.md](timing_signals.md) B 表实测） |
| "趋势分阶段走" | 趋势跟随：均线、突破、年线过滤 | **已覆盖**（plans/02、plans/15 实测） |

⚠ 注意一个陷阱：即使回测发现"0.618 处反弹多"，也区分不出是斐波那契灵，还是
"整数关口/普通支撑压力"灵——0.5 和 50%、0.618 和"跌了四成"在心理上高度重叠。
所以这类验证的教学价值 > 实盘价值。

## 常见坑

- **事后数浪陷阱**：看历史图觉得"浪型好清晰"——那是答案已公布；难点从来不是解释过去，
  是当下不知道自己在第几浪
- **理论越复杂越能自我说服**：任何走势都能找到一种数法圆上 = 一个信号都没说
  （对照：金叉死叉丑是丑，但至少"今天 DIF>DEA 且昨天 ≤"没有任何解释空间，所以它能被回测打脸——
  **能被证明错，是规则的优点不是缺点**）
- **"大师预言"崇拜**：江恩/波浪圈流传的成功案例全是事后精选，没人统计全部预言的命中率
- **把回撤位当精确点位**：就算要用，也当"区域+心理关口"，不当 0.618 精确到小数点
