## 一、作者观点（原文，未改动）

作者：睡觉北窗凉。著作权归作者所有，非商业转载请注明出处。

> 底部抄底指数基金，拉起来有二三十个点利润，跑路。一年做两三次即可，其他时间全部空仓。
> 从 2019 年到 2026 年，指数每年的上半年、下半年都有一次大跌的机会，时间就在 2-4 月份之间。
> 不是指数最低点，是相对底部——短期内超跌，有反弹需求。等到大跌出来之后直接抄底指数基金，
> 一波 15-20 个点，反弹吃完就走，其他时间空仓，一年收益 30-40% 没问题。
> 低点清单：19 年 2 月初、20 年 3 月下旬、21 年 3 月底、22 年 3 月、23 年 3 月、24 年 2 月、
> 25 年 4 月、26 年 4 月。指数基金不会退市、不会 ST，等大盘低点进去，拉起来走人，稳赚钱。

**核心主张拆解**：
1. 每年 2-4 月（及下半年）必有一次大跌，形成"相对底部"
2. 短期超跌 → 有反弹需求 → 抄底吃 15-20% 反弹
3. 一年 2-3 次，其余时间空仓，年化 30-40%
4. 指数不会退市，所以不需要止损

## 二、数据实测检验

数据：上证指数（000001）/ 沪深300（000300），2018-01 ~ 2026-07，新浪源日线。
所有回测统一纪律：**T 日收盘出信号 → T+1 开盘成交（无未来函数），双边成本 0.1%**，
回测区间 2018-07 ~ 2026-07（约 8 年）。

### v1：规律核查 + "深回撤"抄底回测

**"每年 2-4 月大跌"核查**：8 年中 7 年在该窗口（或紧邻）出现 ≥8% 回撤的相对底部 ✅；
例外 2023 上半年（仅 -2.1%）。但作者给的月份有 1 个月级误差（2022 说 3 月实际 4 月底）。

**"一波 15-20 个点"核查**：哪怕精准买在最低点（事后视角），之后 60 个交易日内
反弹 ≥15% 的只有 2019 / 2022 / 2024 三年；多数年份只有 5-12% ❌ 言过其实。

**规则化回测**（跌破 60 日高点 8% 买，+15% 止盈 / 60 日离场）：
上证年化 6.2% / 胜率 75% / 回撤 -20.8%；沪深300 年化 4.0% / 胜率 57% / 回撤 -36.1%。

### v2：方法论修正——什么才算"超跌"（用户指出 v1 缺陷后重做）

**v1 的缺陷**：拿着结论找匹配——窗口里随便找个 -3.2% 的低点就算"验证规律"，
但这种小回撤毫无区分度。实测频率（2019-2026 年均首次跌破次数）：

| 信号 | 上证指数 | 沪深300 |
|---|---|---|
| 距 60 日高点回撤 ≥3% | **年均 7.4 次** | **年均 9.8 次** |
| 距 60 日高点回撤 ≥8% | 年均 3.8 次 | 年均 5.9 次 |
| 10 日内急跌 ≥7%（真·短期超跌） | **年均 1.0 次** | **年均 1.5 次** |

**忠于原意的回测**（10 日跌 7% 买，+5% 止盈 / 20 日离场）：
上证 9 笔胜率 89% 年化 **3.6%** 回撤 **-5.2%**；沪深300 13 笔胜率 77% 年化 **4.3%** 回撤 -8.7%。
止损对照版：上证完全相同（-7% 止损从未触发）→ **作者"指数不止损"在样本内成立** ✅。

### v3：超跌指标对比 & 止盈方式对比

**六种"超跌"定义公平对比**（同一离场：+5% 止盈 / 20 日超期）：

| 超跌定义 | 上证：胜率/年化/回撤 | 沪深300：胜率/年化/回撤 | 评价 |
|---|---|---|---|
| 10 日收益率 ≤ -7% | 90% / 4.0% / -5.2% | 71% / 4.7% / -8.7% | 稀却准，胜率之王 |
| **BIAS20 ≤ -6%**（乖离率） | 89% / 4.6% / -5.3% | **82% / 5.0% / -7.7%** | **两指数都稳，综合最佳** |
| RSI(6) ≤ 20 | 79% / **7.0%** / -7.4% | 68% / 3.8% / -15.1% | 信号多年化高（上证），但回撤大 |
| KDJ 的 D < 20 | 76% / 3.2% / -10.8% | 57% / 2.8% / -13.7% | 平庸 |
| 跌破 BOLL 下轨 | 72% / 4.1% / -11.4% | 54% / 3.2% / -21.2% | 信号太多（年均 6+ 次），失效 |
| 60 日高点回撤 ≥8% | 71% / 4.3% / -11.7% | 48% / 0.5% / -17.4% | 慢半拍，接阴跌飞刀 |

规律：**衡量"短期偏离"的指标（10日收益率 / BIAS / 短周期 RSI）有效**；
信号频繁（BOLL 下轨、60 日回撤）或反应慢的定义，边缘被稀释。

**固定止盈 vs 移动止盈**（同一入场，只换离场）：

| 入场 | 离场 | 上证：胜率/年化/回撤 | 沪深300：胜率/年化/回撤 |
|---|---|---|---|
| 10日跌≥7% | A 固定 +5% / 20日 | **90% / 4.0% / -5.2%** | 71% / 4.7% / -8.7% |
| 10日跌≥7% | B 移动 3%/3% / 20日 | 78% / 3.0% / -9.3% | 69% / 3.2% / -11.8% |
| 10日跌≥7% | C 移动 3%/3% / 60日 | 62% / 1.9% / -9.9% | **83% / 6.1% / -16.2%** |
| RSI6≤20 | A 固定 +5% / 20日 | 79% / 7.0% / -7.4% | 68% / 3.8% / -15.1% |
| RSI6≤20 | B 移动 3%/3% / 20日 | 79% / **8.3%** / -9.3% | 61% / **6.4%** / -18.9% |
| RSI6≤20 | C 移动 3%/3% / 60日 | 65% / 2.4% / **-29.0%** | 61% / 5.1% / -23.0% |

规律：**"博反弹"策略里移动止盈并不占优**——同为 20 日持仓上限时互有胜负（差异在噪声内），
一旦放宽到 60 日"让利润奔跑"，回撤全部爆炸（-29% ~ -36.5%）。
原因：这个策略的利润来源是**恐慌修复的快速反弹**（均值回归），不是趋势；
反弹边缘在 ~20 个交易日内就衰减完了，多拿一天都是在裸奔承受市场本身的涨跌。

### v4：机制分析——超跌为什么会反弹？何时会失效？（用户追问）

脚本：[oversold_mechanism_analysis.py](../../archive/oversold_mechanism_analysis.py)（已归档）。
方法说明：Part 1/2 是**统计研究**（用未来数据算"条件收益"，回答"信号有没有信息含量"），
不是交易回测；Part 3 才是无未来函数回测。

**Part 1 信息含量检验：信号日之后 20 日的收益 vs 普通交易日**（上证指数，沪深300 同向）：

| | 样本 | 20日收益均值 | P(涨≥5%) | P(跌≥5%) |
|---|---|---|---|---|
| 全部交易日（基准） | 2056 | +0.2% | 12% | 10% |
| BIAS20≤-6% 信号日 | 14 | **+3.8%** | **43%** | **0%** |
| 10日跌≥7% 信号日 | 13 | +3.3% | 38% | 0% |
| RSI6≤20 信号日 | 43 | +2.4% | 23% | 5% |

→ 信号**确实有信息含量**（均值是基准的 15-19 倍）；且严格超跌信号之后 20 日内
**"继续跌 5% 以上"的样本为零**——"越跌越抄套牢"在样本内没有发生。

**Part 2 牛熊分组（反直觉 ⭐）**：按信号日是否在 250 日线上方分组，
假设"年线上方的超跌才是错杀"——**被数据否定**：
深度超跌信号 70-80% 发生在年线下方，且表现**更好**（BIAS 信号：年线下方均值 +4.2%
vs 上方 +2.4%；沪深300 年线上方组甚至是负收益）。
**Part 3 回测证实**：加"只在年线上方抄底"过滤器后策略只剩 2 笔交易、年化 0.4%——
过滤器把最赚钱的交易全滤掉了。**这个策略赚的不是"牛市回调"的钱，而是"恐慌极值"的钱，与牛熊无关。**

**Part 4 失败归因**：上证仅 1 笔亏损（-1.1%）、沪深300 仅 2 笔（-2.1% / -1.8%）——
20 日时间止损把单笔亏损结构性地锁死在 -2% 以内。

**机制解释（为什么恐慌极值会反弹）**：
1. **卖压衰竭**：短期价格由边际供需决定。恐慌急跌 = 被迫卖盘（强平、止损、赎回）集中
   释放，卖盘耗尽后很小的买盘就能推高价格（卖方流动性真空）
2. **均值回归**：价格短期偏离基本面锚（均线/估值）过远，吸引逆向资金进场
3. **行为同步化**：恐慌时散户一起割肉，情绪极点常对应短期低点
4. **A股特色**：指数级恐慌常触发政策干预（2024-02 国家队进场、2025-04 汇金增持）

**为什么这个策略不会"越跌越抄"（防守结构，缺一不可）**：
1. 信号门槛够**深**（BIAS≤-6% / 10日跌≥7%）——普通回调全被过滤，只在恐慌极值出手
2. **时间止损**（20 日超期）——不预测底部，反弹不来就走，单笔亏损 ≤2%
3. 标的是**指数**——不会退市归零，均值回归有"锚"；**换成个股逻辑不成立**
4. 一次一笔、**不加仓摊平**——从规则上杜绝"越跌越抄"的行为陷阱

**诚实边界**：信号日样本仅 13-16 个，P(跌≥5%)=0% 是样本内事实不是未来保证；
若出现"指数长期下行且无政策底"（锚本身持续下移，如 1990 后的日本），深跌后还能再深跌
——所以时间止损和仓位上限不是可选项，是这个策略活命的底线。

## 三、最终结论

1. **"每年 2-4 月有相对底部"大体存在**（8 年 7 中），但远没作者说的精确；
   "一波 15-20 点"只在 3/8 年份成立。
2. **收益真相：年化 3%~7%**，胜率 70-90%，与"年化 30-40%"差近 10 倍。
   作者的数字 = 后视镜选点 + 只讲好年份 + 空仓不计时间成本。
3. **策略真正价值在风险控制不在收益**：上证版拿 3.6-4.0% 年化只承受 -5% 回撤
   （卡玛≈0.7，买入持有卡玛≈0.14），是"低波动增强器"，适合作为空仓等待型纪律。
4. **指数选择不是关键，信号定义才是**：v1 口径上证优（波动温和），v2 口径沪深300 优
   （机会更多）；用对超跌指标（BIAS/10日收益率）比选对指数重要。
5. **作者唯一全对的话**："指数基金不止损"——恐慌急跌后再深跌的情形样本内没出现；
   "指数基金不会退市"——宽基指数确实无幸存者偏差问题。

## 四、我们学到的东西（本案例的真正产出）

### 1. 如何判断"超跌"——指标工具箱（按实测有效性排序）

| 指标 | 标准超卖阈值 | 衡量什么 | 实测表现 |
|---|---|---|---|
| **乖离率 BIAS(20)** | ≤ -6% | 价格偏离 20 日均线的距离 | ⭐ 综合最佳，两指数都稳 |
| **N 日收益率**（N=10） | ≤ -7% | 短期急跌（恐慌抛售） | ⭐ 胜率最高（90%），信号最稀 |
| **RSI(6)** | ≤ 20 | 短期涨跌力量失衡 | 信号多、年化高（上证），回撤偏大 |
| KDJ 的 D | < 20 | 9 日内价格相对位置 | 平庸 |
| BOLL 下轨 | 收盘 < MA20-2σ | 统计偏离（2 倍标准差） | 太频繁，失效 |
| 60 日高点回撤 | ≥8% | 中期深度回调 | 太慢，接阴跌飞刀 |

**核心认知：有效超跌信号 = 短期 + 深度 + 稀缺**（年均 1-2 次）。
"跌了一点"（-3% 回撤年均 7-10 次）不是信号是噪音——**判断超跌先看信号频率，太常见的一律无效**。

### 2. 止盈方式要匹配利润来源 ⭐

- **趋势行情**（单边大牛/大熊，如半导体基金、腾讯见顶）→ **移动止盈**碾压固定止盈
  （见 [exit_rules.md](../exit_rules.md) 的真实模拟：+89.7% vs +44.4%）
- **均值回归/博反弹**（本策略）→ **固定止盈 + 短持仓上限**更优；移动止盈互有胜负，
  放宽持仓则灾难（回撤 -29%+）

**别背规则，先问"我的利润从哪来"**：赚恐慌修复的钱，反弹衰竭就走（固定止盈）；
赚趋势延续的钱，不回头不卖（移动止盈）。

### 3. 验证网文策略的方法论（防忽悠三步 + 一记杀招）

1. **拆主张**：把原文拆成可检验的原子命题（大跌存在吗？幅度够吗？）
2. **事后核查**：确认规律不是编的——但警惕"拿着结论找匹配"，
   先统计该信号在全历史出现的频率，太常见 = 无区分度
3. **规则化回测**：翻译成无未来函数的明确规则再测收益——
   事后视角与规则化结果的差距，就是作者吹的水分
4. **杀招：条件收益分布检验**（v4 用过）——信号日的"未来 N 日收益"分布 vs
   全部交易日的基准分布。均值、P(涨≥5%)、P(跌≥5%) 三个数一比，
   信号有没有真实信息含量立刻现形（本案例：均值 3.8% vs 基准 0.2%）。
   再按牛熊/高低位分组，还能回答"什么时候信号会失效"。

### 4. 量价复盘：8 个底部的 K 线组合特征（plans/09，2026-07-26 补）

把作者点名的 8 个底部逐个做量价解剖（[analysis/analyze_bottoms.py](../../analysis/analyze_bottoms.py)），
提炼出可规则化的两条 + 两条"不能用"：

| 特征 | 数据 | 结论 |
|---|---|---|
| 恐慌极值 RSI6 ≤ 25 | 6/8 底部有（2023/2026 浅底没有） | 当"前提条件"用 ✅ |
| 见底次日中阳 ≥ +1.6% | 6/8 底部出现（T+1 确认阳线） | 右侧确认信号 ✅ |
| 放量确认 | 5/8 反弹首日量比 ≤ 1.1x（缩量涨） | ❌ 教科书说法在此失效：恐慌底"跌缩量涨也缩量"=卖压衰竭 |
| 长下影（金针探底） | 5/8 底部区域出现 | ❌ 非必要（2019/2021 没有），只能当加分项 |

**左侧 vs 右侧实测**（同离场 +5%/20 日，2018-07~2026-07 上证）：
右侧确认版（bottom_reversal：超跌+中阳反包才买）21 笔/57%/年化 3.1%/回撤 -10.0%，
**跑输**左侧深度版（bias_oversold）9 笔/89%/年化 4.6%/回撤 -5.3%。
原因：恐慌修复的肉中位才 6.2%，确认阳线先涨掉 2-4% 再进场 = 利润池让掉一半；
而右侧"防假底"的价值已被 20 日时间止损覆盖。**右侧确认适合趋势策略，不适合博反弹。**

**"真谷"事前不可识别（2026-07-26 问答补充）**：2022 年两次底在当时的读数几乎
一样——03-15 假底 RSI6 12.5 / BIAS20 **-9.8%** / 60日回撤 -16.6%，04-26 真谷
RSI6 10.0 / BIAS20 -9.1% / 60日回撤 -18.1%（假底 BIAS 还更深）。"真谷 = 之后不再
创新低"只能事后确认；双底规律也写不成规则（2025-04 是单底 V 型反例）。
且"识别越可靠、进场越贵"：左侧深恐慌 → 确认阳线 → 趋势反转确认，确定性递增、
利润递减，等形态确认完利润常只剩零头。**策略对恐慌点机械全做、算总账（假底亏
2~5%、真底赚 7%+），真谷的利润是"每次都没缺席"换来的，不是识别出来的。**

## 五、实操注意（支付宝场外基金渠道）

- ⚠️ **7 天惩罚性赎回费**：本策略多笔止盈仅持有 3-6 个交易日，场外基金持有 <7 天
  收 1.5% 赎回费，会砍掉单笔利润的 1/3 → 必须加"最少持有 7 天"约束，或用场内 ETF
- 必须选 **C 类份额**（免申购费、超 7 天免赎回费）
- 样本量警告：8 年仅 9-30 笔交易，胜率 89% 看着美，统计置信度低，期望收益按区间理解
- 该策略全年 90% 时间空仓，空仓期资金应放货币基金/国债逆回购，别让"空仓"= 活期
