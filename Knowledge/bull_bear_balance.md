# 多空力量对比：流派速览与"全是代理"的现实校准（2026-07-28）

> 来源：用户问答沉淀——"有没有什么流派是通过分析多空力量对比来预测走势的？"
> 定位：这是**价格之外的一整个方法族**。量价派详述在 [volume_price.md](volume_price.md)，
> 本文件画全族地图。

## 一句话核心

价格只是多空博弈的**比分牌**，这一族方法试图直接称量"两队各有多少人、多少弹药"。
但先记住一个祛魅事实：**每一笔成交都必然有一个买家和一个卖家**——"多空力量"无法被
直接测量，所有方法都是带假设的**代理指标**（proxy），差别只在假设是什么、容不容易被造假。

## 流派速览（按数据门槛从低到高）

| 流派 | 称量什么 | 代表指标 | 主要假设 / 破绽 |
|---|---|---|---|
| **量价派** | 钱的投票积极性 | OBV 能量潮、量价背离 | 见 [volume_price.md](volume_price.md)；日频形态大多被套利 |
| **资金流派** | "主力"（大单）在买还是卖 | 主力净流入、DDX | ①"净流入"严格说 = 主动买入成交占比（以卖方价成交 = 买方更急），不是钱凭空变多；②主力可以拆单伪装散户 |
| **筹码分布** | 持有人成本结构：上方套牢盘（潜在卖压）、下方获利盘（潜在回吐） | CYQ 筹码峰、获利比例 | 没有真实账户数据，靠"换手衰减"模型推算，不同软件结果不同 |
| **市场广度** | 指数上涨是"普涨"还是少数权重股拉抬 | 腾落线 ADL、涨跌家数比 | 只适用于指数/全市场，不适用于个股 |
| **持仓情绪** | 杠杆资金与期权的真实下注 | 融资融券余额、期指基差、期权 put/call 比 | 是"仓位"不是"意图"——高融资余额既 = 看多，也 = 反转时的踩踏燃料 |
| **订单流/盘口** | 逐笔委托与挂单队列的真实博弈 | Level-2 盘口、订单流失衡 | 高频领域，日频框架够不着；头部量化主战场之一 |

> 名词一句话：OBV = 涨日成交量记正、跌日记负，累加成线（"量在价先"）；
> 腾落线 ADL = 每日上涨家数 − 下跌家数，累加成线；
> 融资融券 = 向券商借钱买股（融资=杠杆多头）/ 借股卖出（融券=空头，A股规模很小）。

## 各自怎么"预测"（经典说法）

- **OBV**：价格横盘但 OBV 上升 = 有人悄悄吃货 → 后续看涨
- **资金流**：连续主力净流入 + 价格滞涨 = "吸筹"；净流出 + 滞涨 = "出货"
- **筹码**：上方密集套牢峰 = 反弹到那里会遇到"回本卖压"（**压力位的微观解释**）；
  低位单峰密集 = 换手充分、抛压出清
- **广度**：指数新高但 ADL 没新高 = 外强中干（广度背离，与 MACD 顶背离同构）
- **融资余额**：持续上升 = 杠杆多头增兵；但极端高位 = 拥挤，反转时放大跌幅

## 现实校准

- 这一族最大的教训：**代理可以被操纵，比分不会说谎**。价格本身无法造假，
  资金流/筹码都是推算——所以它们的位置是"辅助证据"，不是"主信号"
- 你其实已经在用最便宜的多空代理：RSI（涨跌幅单边度）和量价背离，
  只用收盘价+成交量，已在体系内并实测过
- 真正"直接"看多空的是订单流，但那是 tick 级数据 + 重工程，
  与本项目日频低频定位不符，明确不做

## 渠道适用性（对自己三个场景）

| 场景 | 能用吗 | 原因 |
|---|---|---|
| 支付宝场外基金 | ❌ | 基金净值无成交量、无盘口；最多用对应指数的资金面作大盘参考 |
| 腾讯卖出时机 | ⚠️ 辅助 | 港股有真实成交量，OBV/量价背离可作离场框架参考项 |
| A股指数/个股练手 | ✅ 部分 | 日线级代理（OBV、ADL、融资余额）数据可得、可进框架回测；资金流和订单流够不着 |

## 常见坑

- **把"主力净流入"当圣旨**：统计口径各软件不同 + 拆单造假，日频预测力弱
- **融资余额高 = 纯利好**：它也是拥挤度——2015 年去杠杆踩踏就是杠杆多头互相踩踏
- **筹码峰当精确点位**：模型推算值，换家软件就挪位置，只能当"区域"
- **拿广度指标评个股**：ADL 是全市场指标，对单只股票无意义
- **忘了代理与价格背离时要信谁**：资金流说"吸筹"但价格阴跌，先信价格
