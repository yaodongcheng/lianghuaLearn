# 05 腾讯（00700.HK）卖出时机分析

- **状态**：待规划
- **创建**：2026-07-24
- **前置**：01（数据源，需扩展港股接口 `stock_hk_hist`）

## 背景
用户持有腾讯股权激励 233 股，受政策限制**只能卖不能买**。需求：找一个"合适的时间点"卖出。
注意定位：这是**一次性卖出决策的辅助分析**，不是可反复验证的交易策略——回测能验证策略，验证不了"这次该哪天卖"。

## 目标
1. 拉取腾讯港股历史数据（前复权），分析当前所处的趋势位置：均线系统（MA20/60/250）、近一年波动区间、关键支撑压力位
2. 设计**规则化的卖出计划**，把模糊的"什么时候卖"变成可执行规则，候选：
   - **分批卖出**：如分 3 批、每月一批 → 牺牲最优换取确定性，抹平时点运气
   - **趋势触发**：如跌破 MA60 卖出剩余部分 → 用规则代替盯盘和情绪
   - **目标价触发**：回到某价位区间（如前高附近）卖出一批
3. 输出一页纸结论：当前趋势状态 + 2~3 种卖出规则在历史情景下的结果对比 + 每种规则的代价与适用前提

## 验收标准（草案）
- [ ] 腾讯 K 线图（含均线、关键位置标注），趋势状态有明确描述
- [ ] 至少 2~3 种卖出规则的历史情景对比表
- [ ] 每种规则写清"代价"（放弃了什么、防住了什么）

## 重要认知（必须写进最终结论）
- 量化分析只能提供**规则与概率**，不能预测股价；任何"精确逃顶"的承诺都不可信
- 对一次性卖出决策，**分批**往往是最稳妥的风险管理手段
- 税费、外汇结算、卖出窗口等实操问题由用户自行向券商/公司确认
