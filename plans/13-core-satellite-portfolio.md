# 13-核心卫星组合回测

## 背景

混合策略（牛熊切换，计划 12 关联）四轮实验全部指向同一结论：
上证的牛市有三种性格（恐慌底/尖峰/慢牛），单一规则各抓一种，
唯一通吃的结构是"一直在场 + 恐慌增强"的核心-卫星配置。
（论证过程见 Knowledge/hybrid_vs_core_satellite.md）

## 目标

回测验证：70% 核心仓（一直持有上证）+ 30% 卫星仓（bottom_reversal）
的组合净值，是否做到"牛市不掉队、熊市少亏钱"。

## 验收标准

- [x] 组合净值曲线 vs 纯持有 vs 纯策略的对比图（PNG）
- [x] 权重敏感性（50/50、70/30、80/20、100/0、0/100）全表
- [x] 三次牛市（2019Q1 恐慌底、2024-09 尖峰、2025-04 慢牛）期间
      组合是否都"在场"（图上标色带直观验证）
- [x] 结果按口径如实记录（含"闲置资金货基收益未计入"的保守口径说明）

## 口径约定

- 两笔钱分开记账、中途不划转（买入并任其漂移，不再平衡——最贴近
  支付宝基金"两个基金分别持有"的真实操作）
- 卫星仓空仓期现金收益按 0 计（保守口径；实际放货基约 +1.5%/年，
  会进一步抬高组合）
- 成本：卫星仓双边各 0.1%；核心仓一次买入，成本忽略

## 结果（2026-07-27 完成）

见 analysis/analyze_core_satellite.py 输出与 data/core_satellite_000001.png。

| 组合 | 总收益 | 年化 | 最大回撤 | 夏普 |
|---|---|---|---|---|
| 100% 核心（纯持有） | +37.4% | +4.0% | -27.3% | 0.06 |
| 80% + 20% | +39.8% | +4.2% | -22.6% | 0.09 |
| 70% + 30% | +41.0% | +4.4% | -20.4% | 0.10 |
| 50% + 50% | +43.4% | +4.6% | -16.0% | 0.14 |
| 0%（纯卫星） | +49.5% | +5.1% | -12.2% | 0.23 |

结论：
1. 三次牛市色带内组合全程在场 ✓（核心仓的功劳，与卫星信号无关）
2. 70/30 组合收益略高于纯持有（+41.0% vs +37.4%），回撤 -20.4% vs
   -27.3%（约打 75 折），且卫星空仓期现金收益未计入（保守口径）
3. ⚠️ 如实记录：本 8 年窗口内**纯卫星各项最优**——因为 bottom_reversal
   在上证本身已跑赢持有且回撤减半。组合的价值不在提升历史收益，
   而在**分散"卫星策略未来失效"的风险**：若某天超跌打法衰减，
   核心仓保证牛市不掉队。这是稳健性（robustness），不是收益增强。
4. 权重 50/50~100/0 结论方向一致，非单点调参。
