# 06 知乎"抄底指数"策略验证

> 状态：已完成 | 开始：2026-07-25 | 完成：2026-07-25

## 背景
知乎回答（已存 [Knowledge/zhihu/吃超跌恐慌修复策略.md](../Knowledge/zhihu/吃超跌恐慌修复策略.md)，原名 strategy1.md）声称：
- 指数每年上半年 2-4 月（及下半年）都有一次大跌，形成"相对底部"
- 抄底指数基金，反弹 15-20 个点走人，一年做 2-3 次，年化 30-40%
- 给出的低点清单：19年2月初、20年3月下旬、21年3月底、22年3月、23年3月、24年2月、25年4月、26年4月

## 目标
1. 用真实数据检验"每年 2-4 月大跌"的规律是否成立
2. 把模糊的"相对底部"变成**明确、无未来函数**的买卖规则，回测验证
3. 对比上证指数（000001）vs 沪深300（000300），看哪个更适合该策略

## 验收标准
- [x] 每年的大跌事实核查表（跌幅、时间、后续反弹幅度）
- [x] 规则化策略在两个指数上的回测结果（年化、回撤、胜率、交易次数）
- [x] 对照 Knowledge/backtest_checklist.md 逐项自检并记录
- [x] 明确结论：策略可信度 + 适合哪个指数

## 步骤
1. 拉取两指数 2018-2026 日线（2018 年数据用于算 2019 年初的前期高点）
2. 事实核查：每年 2-4 月窗口内的最大回撤 vs 全年其他时间
3. 规则化：例如"收盘较 60 日高点回撤 ≥X% → 次日开盘买；+15% 止盈 / 移动止盈 / 超期离场"
4. 回测对比，做参数扰动测试（防过拟合）
5. 自检清单逐项过

## 结论摘要（2026-07-25）
验证脚本：[zhihu_strategy1_verify.py](../archive/zhihu_strategy1_verify.py)（已归档，重跑见 archive/README.md）

1. **"每年 2-4 月大跌"规律：大体成立但不精确**。2019-2026 八年中 7 年在该窗口（或紧邻）
   出现 ≥8% 回撤的相对底部；例外是 2023 上半年（仅 -2.1%）。作者给的月份有 1 个月级
   误差（2022 说 3 月实际 4 月底、2026 说 4 月实际 3 月下旬）。
2. **"一波 15-20 个点"言过其实**：精准买在最低点（事后视角），之后 60 个交易日内
   反弹 ≥15% 的只有 2019 / 2022 / 2024 三年；多数年份只有 5-12%。
3. **规则化回测（无未来函数）：上证年化 6.2% / 胜率 75% / 最大回撤 -20.8%，**
   **沪深300 年化 4.0% / 胜率 57% / 回撤 -36.1%**（同期买入持有约 4.3% / 36.4%）。
   上证指数版本明显优于沪深300——**该策略更适合上证指数**，与年化 30-40% 的宣传差距大。
4. 参数扰动：基准参数（8%/15%）恰好是表现最好的格子 → 结果偏乐观，真实期望要打折。
5. 作者高收益的来源：后视镜选点（买在精确底部）+ 只讲好年份 + 空仓不计时间成本。

## v2 补充验证（2026-07-25，用户指出 v1 Part A 方法论缺陷后追加）
脚本：[zhihu_strategy1_oversold.py](../archive/zhihu_strategy1_oversold.py)（已归档）

**用户批评（成立）**：v1 Part A 是"拿着结论找匹配"——窗口里随便找个低点（-3.2%）就算
验证规律，但这种小回撤毫无区分度。数据证实：**距 60 日高点回撤 ≥3% 年均出现 7.4 次
（上证）/ 9.8 次（沪深300）**；≥8% 年均 3.8/5.9 次；真正的"短期超跌"（10 日急跌 ≥7%）
年均仅 1.0/1.5 次。

**v2 规则（忠于"短期超跌博短期反弹"原意）**：10 日收益率 ≤-7% → 次日开盘买；
+5% 止盈 / 20 日离场；成本 0.1%。结果（2018-07 ~ 2026-07）：
- 上证：9 笔，胜率 89%，年化 **3.6%**，最大回撤 **-5.2%**（同期买入持有 37.4%/年化4.3%）
- 沪深300：13 笔，胜率 77%，年化 **4.3%**，最大回撤 -8.7%（买入持有 36.4%）
- 止损对照版：上证完全相同（-7% 止损从未触发）；沪深300 略差（3.8%）
  → 作者"指数不止损"的说法在本样本内成立
- 参数扰动范围 0.5%~7.6%，参数敏感；放宽阈值到 -5% 交易变多年化升到 ~7%
- **样本仅 9-13 笔，统计置信度低**

**新认知**：
- 策略真实价值不在收益（年化 3-5%），而在**风险控制**：-5% 回撤拿 3.6%（卡玛≈0.7），
  对比买入持有约 -30% 回撤拿 4.3%（卡玛≈0.14）——是"低波动增强器"，不是暴富工具
- 策略只能赚"恐慌修复"的钱：2024-09 史诗级反弹前是阴跌而非急跌，信号完全错过
- ⚠️ 实操冲突：多笔止盈仅持有 3-6 个交易日，**支付宝场外基金持有 <7 天有 1.5%
  惩罚性赎回费**——基金渠道执行此策略必须加"最少持有 7 天"约束或用场内 ETF

## v3 超跌指标 & 止盈方式对比（2026-07-25，用户提出的两个学习方向）
脚本：[zhihu_strategy1_oversold_v3.py](../archive/zhihu_strategy1_oversold_v3.py)（已归档；v3 是 plans/07 框架的回归基准）

**Q1 什么指标能证明超跌？** 六种定义公平对比（同一离场 +5%/20日）：
- 综合最佳：**BIAS20 ≤ -6%**（两指数都稳：上证 89%/4.6%/-5.3%，沪深300 82%/5.0%/-7.7%）
- 胜率之王：**10日收益率 ≤ -7%**（上证 90%）
- RSI6≤20 信号多、上证年化最高 7.0% 但回撤大；KDJ-D 平庸；
  BOLL 下轨（年均 6+ 次）和 60 日回撤（慢半拍）失效
- 认知：**有效超跌信号 = 短期 + 深度 + 稀缺（年均 1-2 次）**；太常见的一律无效

**Q2 止盈该用移动止盈吗？** 数据否定了这个直觉：
- 博反弹策略里移动止盈不占优：同为 20 日上限互有胜负（差异在噪声内）；
  放宽到 60 日"让利润奔跑"回撤全部爆炸（-29% ~ -36.5%）
- 原因：利润来源是**恐慌修复的快速反弹（均值回归）**，边缘 ~20 日内衰减完；
  移动止盈适合的是趋势行情（exit_rules.md 的半导体/腾讯案例）
- 沉淀认知：**止盈方式要匹配利润来源**——均值回归用固定止盈+短持仓，趋势用移动止盈

## v4 机制分析（2026-07-25，用户追问：超跌为什么反弹？越跌越抄怎么办？）
脚本：[oversold_mechanism_analysis.py](../archive/oversold_mechanism_analysis.py)（已归档）

- **信息含量检验**（信号日 vs 全部交易日的未来 20 日收益分布）：
  BIAS 信号日 均值 +3.8% / P(涨≥5%)43% / **P(跌≥5%)0%**，基准日 +0.2%/12%/10%
  → 信号有真实信息含量，"越跌越抄"在样本内未发生
- **反直觉**：年线过滤器假设被数据否定——深度超跌信号 70-80% 在年线下方且表现更好；
  加过滤器后只剩 2 笔交易、年化 0.4%。**策略赚的是"恐慌极值"的钱，与牛熊无关**
- **防守结构四要素**（不套牢的原因）：深阈值信号 + 20 日时间止损（单笔亏损≤2%）
  + 指数标的（有均值回归的锚）+ 不加仓摊平
