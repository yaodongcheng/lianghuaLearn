## 背景与目标

用户指定上证指数 8 次局部底部（19年2月初 / 20年3月下旬 / 21年3月底 /
22年3月 / 23年3月 / 24年2月 / 25年4月 / 26年4月——即知乎作者"睡觉北窗凉"的

1. 分析每个底部附近的 **K 线组合 + 量价关系** 特征，提炼入场信号
2. 分析每个底部之后的 **反弹过程**，提炼离场规则
3. 写成 quant/strategies/ 新策略并回测验证

## 分析结论（analyze_bottoms.py 输出）

### 底部定位（A 表）：用户给的月份有误差
- 2019 实际底在 **1 月初**（01-03，2440 那波）；2021 实际在 **3 月上旬**（03-10）；
  2022 三月窗内底是 03-15（更深的大底在 4 月底，不在用户窗口）
- 其余 5 个（2020-03-23 / 2022-03-15 / 2023-03-16 / 2024-02-05 / 2025-04-07 / 2026-04-03）基本准

### 入场共性（B/C 表）→ 信号
1. **恐慌极值**：6/8 底部 RSI6 ≤ 25；2023（35.1）/2026（37.4）没有——它们反弹也最弱，漏掉合理
2. **确认阳线**：6/8 底部次日涨幅 ≥ +1.6%（中阳反包 = 多头反击，右侧可观察）
   → 规则化：前 3 日内 RSI6 ≤ 25 且当日涨幅 ≥ 1%（首日触发），2 个参数
3. **量能不能当条件**（反直觉）：5/8 反弹首日量比 ≤1.1x——恐慌底"跌缩量、涨也缩量"
   （卖压衰竭），教科书式"放量确认"会误杀 2020/2021；长下影同理（5/8 有，非必要）

### 反弹共性（D 表）→ 离场
- 20 日内最大浮盈中位 6.2%，+5% 达成 6/8（中位 7 天）→ **固定止盈 +5%**
- 拿满 20 天 8/8 为正（+2.9%~+14.0%）→ **20 日超期兜底**
- 反弹峰值日 RSI6 全部 ≥71（阈值不稳，只记录不进规则）；不放宽持仓（知乎 v3 已证会炸）

## 回测结果（2018-07 ~ 2026-07，双边 0.1%，T+1）

| 口径 | 结果 |
|---|---|
| 全样本（上证） | 21 笔 / 胜率 57% / 平均每笔 +1.2% / 年化 +3.1% / 回撤 -10.0% |
| 对照 bias_oversold（左侧，同离场） | 9 笔 / 89% / +4.1% / +4.6% / -5.3% |
| 参数扰动 rsi_level 20/25/30 | 15/21/30 笔，年化 +3.5%/+3.1%/+2.7%——平滑无悬崖 ✓ |
| 参数扰动 confirm_ret 0.8%/1.0%/1.5% | 23/21/16 笔，年化 +3.3%/+3.1%/+3.6%——平滑无悬崖 ✓ |
| 离场扰动 +4%/+5%/+6% | +1.1%/-15.4% · +3.1%/-10.0% · +3.7%/-10.0%——+5% 是稳定区 |
| 跨标的（沪深300，同参数） | 26 笔 / 58% / 年化 +3.1%（与上证一致）但回撤 -28.8% ⚠ |
| 样本内 2018-07~2022 | 13 笔 / 54% / 年化 +4.2% / 回撤 -7.7% |
| 样本外 2023~2026-07 | 8 笔 / 62% / 年化 +1.7% / 回撤 -8.6%（变薄但未变负） |

**核心教学结论：右侧确认在本场景跑输深度左侧。** 恐慌修复反弹的肉中位才 6.2%，
确认阳线先涨掉 2-4% 再进场，等于把利润池让掉一半；而"防假底"的价值在指数恐慌底
场景被时间止损（20 日超期）覆盖了。右侧确认更适合趋势策略，不适合博反弹。

## 离场修正记录（2026-07-26 当天，用户质疑驱动）

**用户质疑**：初版 +5%/20日 在 2025-04 这笔只吃 +4.9%，而反弹实际到 +9.5%（05-14
收盘 3404，买入价 3110）。**事实属实**（甚至还续涨到 06-25 的 3456，+11.1%）。

**但没有按单一情节定制**，而是全样本对比 7 种离场（同一入场）：

| 离场 | 笔数 | 胜率 | 年化 | 回撤 | 关键事实 |
|---|---|---|---|---|---|
| 初版 +5%/20日 | 21 | 57% | +3.1% | -10.0% | 2025-04 这笔 +4.9% |
| **修正 +7%/30日** | 21 | 62% | **+5.1%** | -12.2% | 这笔 +6.9%；邻域 +6~8%/30~40日全平台 |
| +7%/40日 | 19 | 63% | +5.0% | -13.5% | 同平台 |
| +7%/50日 | 16 | 56% | +1.1% | -17.8% | ⛔ 悬崖 |
| 纯60日 / +8%60日 / 移动60日 | 13~18 | — | +1.9~3.6% | **-29~-32%** | ⛔ 回撤爆炸 |

**60 日版最讽刺的事实**：连 2025-04 这笔都没成交——钱还被 2025-01-15 的持仓锁着，
信号来了干瞪眼。**长持仓的隐性成本 = 锁仓错过后续信号。**

**意外发现**：新离线下左/右侧结论反转——bias_oversold（左侧）年化 3.3% vs
bottom_reversal（右侧）5.1%。原因：左侧信号又稀又快，短止盈效率最高；右侧信号多，
长止盈积少成多。**评价入场必须固定离场，反之亦然。**

修正后官方口径（run.py）：21 笔 / 胜率 62% / 平均每笔 +2.0% / 总收益 +49.5%
（同期买入持有 +37.4%）/ 年化 +5.1% / 回撤 -12.2% / 卡玛 0.42。

  定义 + D 去止盈版）：胜率 65% 略升但年化 4.3~4.4% < 现状 5.1%——展期锁仓的时间
  成本吃掉收益；且"阴线才卖"属卖晚家族（阴线出现=跌已开始，D 版 2020-02 单笔
  +8.0%→-0.2% 全吐）。结论：噪声级更差，不采纳。**元警告：同一 21 笔上已试 ~12 种
  离场，多重比较在悄悄过拟合——以后改默认规则要求优势超出噪声 + 跨标的成立。**
- 2022-03-16 信号被冷却期挡掉（03-08 刚超期卖出，冷却 10 天）——如实呈现，
  不为抓底部调冷却参数（那才是过拟合）。
- 沪深300 回撤 -28.8% 的诚实解读：2023-2024 阴跌段连续假反弹止损叠加，
  时间止损锁单笔 ≤5%，但锁不住"连续做连续错"的 equity 回撤。
