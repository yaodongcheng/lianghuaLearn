## 背景与目标

用户要求 run.py 支持多策略一起跑比选，并提出图面设计（方向正确）：
- 买卖点标注：每个策略单独一个子图（画一起会重叠）
- 净值曲线：多策略放进同一个子图对比

## 验收标准

- [x] run.py：`STRATEGY` 给名单（或 CLI 逗号分隔）→ 比选模式；给字符串 → 单策略模式（现状不变）
- [x] 比选产出：文字对比表（compare_table）+ 对比图 PNG
      （n 个策略价格子图各标买卖点 + 底部共享净值图含买入持有）
- [x] 图例/标注不压不叠（沿用 plans/10 防重叠三招 + 图例只在第一个价格子图）
- [x] 借机收口：基金 min_hold 调整逻辑出现第三次 → 下移到 exits.adjust_for_fund
      （report.py 148→145 行 / plot.py / plot_compare.py 三处共用）
- [x] quant/ 每模块 <150 行（exits 101 / plot 125 / plot_compare 71 / report 145），
      test_framework.py 全绿

## 笔记

- **复用靠抽取，不靠复制**：plot.py 把价格子图抽成 `_price_panel(ax, ...)`，
  单策略图（plot_trades）和比选图（_compare_chart）共用——两种图永远"说同一种语言"，
  以后改图面语言（比如换配色语义）只改一处。比选图用 `legend=(i==0)` 只在首个子图放图例。
- **净值图例直接带"年化/回撤"**：对比时眼睛不用在标题和曲线之间来回切换。
- **三处入口的基金口径第三次出现时下移**（plans/10 笔记预告过）：adjust_for_fund
  放 exits.py（ExitSpec 的"家"），report/plot/plot_compare 各瘦 2-3 行。
- run.py 接口设计：STRATEGY 字符串=单策略、名单=比选；CLI `--strategy a,b` 逗号分隔。
  单策略路径行为零变化（文字报告+单策略图）。
- **超额收益子图（用户提议，2026-07-26 当天补）**：比选图最底部加"策略净值÷大盘净值−1"
  面板，图例带期末超额 + 跑赢时间占比。首图就验证了用户的观察：bottom_reversal
  跑赢 94% 时间（期末 +8.8%），bias_oversold 只跑赢 66%（期末 +4.7%）。
  曲线形状教学点：**空仓型抄底策略在暴跌段"跳涨"（收割）、在牛市段"阴跌"（保险费）**——
  跑赢时间少 ≠ 策略差，看期末超额 + 回撤能否承受。
