## 工作方式
1. **开始新任务** → 在本索引登记 + 新建计划文件（命名 `NN-名称.md`，两位数字递增）
2. **计划文件内容**：目标 / 验收标准 / 步骤清单 / 执行中踩的坑与笔记
3. **任务完成** → 更新状态、填完成日期；有价值的坑转入 `Knowledge/` 对应文件
4. 状态取值：`待规划` / `进行中` / `已完成` / `搁置`
